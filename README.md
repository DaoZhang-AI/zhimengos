# 📱 织梦OS

SillyTavern 的模拟手机:在酒馆里和角色线上聊天。以后社交、直播都挂在这一部手机里。

[🦋 织梦者](https://github.com/DaoZhang-AI/zhimengzhe) 的子模块之一,但独立成扩展,单独装单独更。

作者:@不如就叫我道长吧

## 现在做到哪了

**这一版是能看能点的壳,里面是示例数据,还不会真的发消息。**

顺序是先做前端再接数据,理由不是想早点看到东西,而是**手机长什么样决定了数据怎么存**:有几个会话、一条消息带哪些字段、联系人怎么表示,不看见屏幕就只能猜。

已经有的:

- **可拖的悬浮手机图标**,位置会记住,窗口缩放时自动拉回可视范围。**可以藏起来**,藏了之后从设置里照样能开。
- **有新消息时手机上会多一个摇动的铃铛**。不用红点也不用辉光,常驻元素上那两样太吵。
- **竖屏手机界面**:白壳黑屏、刘海、状态栏、主屏图标、会话列表、聊天窗。电脑上也是竖屏,不做横屏版。
- **手机可以用和主线不同的连接和模型**,回一条消息不需要好模型。

## 安装

酒馆里点「扩展」→「安装扩展」,粘这个地址:

```
https://github.com/DaoZhang-AI/zhimengos
```

装完**刷新一次页面**,插件代码是开页面时才加载的。

也可以在 [🦋 织梦者](https://github.com/DaoZhang-AI/zhimengzhe) 的「我的插件」里一键装和一键更新。

## 关于 api

**手机的请求走酒馆自己的通道**,不是浏览器直连。这一点是刻意的:

- 对话请求本来就是酒馆服务端发出去的,所以走酒馆通道时,对面看到的**就是**酒馆在发,不是"像"酒馆。很多公益站不允许脱离酒馆使用,这条很重要。
- 浏览器直连有三个各自独立的硬伤:密钥暴露在前端、CORS 基本挡死、来源一眼是浏览器。

**本插件不存任何密钥。** 手机用的连接是从这两个地方读的:

1. 酒馆自带的「连接配置」(connection-manager),人人都有
2. 第三方扩展 API Config Manager,没装的人自动看不到这一组

设置里那个「加一条新连接」的表单也是**写进酒馆**的:密钥进酒馆的密钥仓库,地址进酒馆的连接配置,本插件一个字都不留。

## 关于测试按钮

**这里没有连通性测试按钮,以后也不会有。** 探测性的请求会让公益站把用户拉黑,能不能用请自己判断。

「加载模型」不算探测:拉模型列表是任何客户端连上去都会做的正常动作,酒馆自己每次切换连接也会拉一次。

## 换图标

悬浮图标是三张 png,想换自己替掉就行:

- `assets/phone.png` 平时
- `assets/bell.png` 有新消息时叠上去摇的那个铃铛
- `assets/phone-new.png` 铃铛那张没放时的退路,整张换成它

哪张缺了都会自动退回画出来的图标,不会开天窗。

## 兼容

- 只用酒馆自己的公开接口,不修改酒馆本体任何文件
- 卸载或禁用后所有改动自动失效,不留残留
